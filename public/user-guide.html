1. Overview & Core Philosophy

The Engineering Task & Work Manager is a high-density, professional deliverable management platform engineered specifically for offshore oil & gas, EPC (Engineering, Procurement, Construction) projects, and multidisciplinary design teams.

💾 100% Local SQLite Ownership

Runs directly with an embedded SQLite database (data/app.db) persisted to disk. No complex database servers or cloud setups required.

⚡ Zero-Jitter Desktop Density

Every table row, status change, and discipline switch occurs with zero screen flicker and zero text shifting. Built for engineering speed.

👥 Multidisciplinary Interfaces

Native tracking of interface disciplines: Process, Piping, Mechanical, Electrical, Instrumentation, Structural, Safety, Pipeline, EMT, and PMT.

📅 1-Click MS Teams Integration

Right-click any date on the calendar to schedule MS Teams meetings with a direct 1-click Join link for all team members.

Language Discipline: All application UI labels, tables, dialogs, charts, and notifications are 100% strictly in technical English. The built-in AI technical assistant can converse with users in Vietnamese while maintaining English technical terminology.

3. Master Task List Grid & Inline Editing

The Master Task List (TaskListView.tsx) provides a dense engineering grid with zero-refresh inline editing:

Table Columns & Inline Controls

  • Checkbox: Selects rows for floating batch operations (Batch Status, Batch Priority, Batch Delete).
  • Priority: Dropdown badge (CRITICAL, HIGH, MEDIUM, LOW).
  • Status: State machine controlled (IN PROGRESS, WAITING, DONE, TODO).
  • Task Title & Scope: Single-click to select row with rounded blue border; double-click or press Enter to open Task Details Modal.
  • Project & Package: Tag identifying the EPC contract and procurement package code.
  • PIC (Persons In Charge): Up to 3 overlapping circular avatars. Click to open the multi-select assignment popup with instant search and inline member creation.
  • Discipline: Inline selector with disciplinary colors (Instrument, Process, Piping, Mechanical, Electrical, Structural, etc.). Updates optimistically with zero screen flicker!
  • Target Deadline & Forecast Finish: Tracks initial commitment vs forecast finish dates and variance.
  • Progress: Compact percentage indicator.
  • Actions: Quick toggle complete (✓) and delete (🗑️).
Authoritative State Machine: Marking a task as DONE automatically sets progress to 100% and stamps completed_date. Reverting from DONE to WAITING caps progress at 50% and clears completed_date.

4. Deadlines Calendar & MS Teams Meetings

The Calendar View provides a comprehensive monthly timeline mapping task deadlines and scheduled engineering review sessions.

Scheduling MS Teams Meetings

1
Right-Click on Any Calendar Day Right-click (or secondary click) on any date cell to summon the context menu:
  • 📹 Add MS Teams Meeting: Opens the meeting scheduler with the date preselected.
  • 📋 Add New Task: Creates a new deliverable with deadline pre-filled.
2
Fill in Meeting Details Enter Meeting Title, Date, Start/End Time, All-Day toggle, Room/Location, Organizer, Agenda notes, and the MS Teams Meeting Link (URL).
3
1-Click Direct Join Meeting cards on the calendar display an MS Teams icon. If a meeting link is present, a blue Join button appears directly on the card. Click it to enter the meeting immediately in a new browser tab.
Corporate Security Friendly: Does not require company Azure Active Directory administrator consent or external calendar permissions. All meetings are saved locally in the SQLite database and can be edited or deleted anytime.

10. Cloud Deployment & Cloudflare Guide

How to host the web application for 24/7 global accessibility:

Option A: Cloudflare Tunnel (Recommended — Free & Secure)

Exposes your running application to the internet through Cloudflare without open ports or firewall changes:

# 1. Start application locally
npm run build && npm start

# 2. In another terminal, run Cloudflare Tunnel
cloudflared tunnel --url http://localhost:3000

Cloudflare generates a secure HTTPS URL (e.g. https://your-tunnel.trycloudflare.com) that can be opened anywhere.

Option B: Automated Cloud Hosting (Render.com + Cloudflare DNS)

  1. Push your repository to GitHub.
  2. Log into Render.com using GitHub and create a New Web Service.
  3. Set Build Command to npm run build and Start Command to npm start.
  4. In Cloudflare DNS, add a CNAME record pointing your custom domain to Render with the orange proxy cloud enabled (🟠 Proxied).

Option C: Docker Container

A multi-stage production Dockerfile is included in the root directory:

docker build -t task-manager .
docker run -d -p 3000:3000 -v $(pwd)/data:/app/data --name task-app task-manager
